# SentinelScope

SentinelScope is a beginner-friendly cybersecurity + data science project using Go and Python.

## Features
- Web log ingestion API in Go
- CSV-based log analysis
- Machine learning anomaly detection
- Attack visualization dashboard
- Suspicious login detection

## Technologies
- Go
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Setup

### Clone Repository
```bash
git clone https://github.com/thelkotolsantosh/sentinelscope.git
cd sentinelscope

INSTALL DEPENDENCIES
pip install -r requirements.txt

Run Analyzer
python src/analyzer.py

Run Dashboard
streamlit run dashboard/dashboard.py

Run Go API
go run api/main.go

Multiple failed login attempts
